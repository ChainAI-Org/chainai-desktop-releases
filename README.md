# ChainAI desktop downloads

Official ChainAI desktop installers published by **Workado, LLC**.

1. Sign in to [ChainAI](https://app.chainai.com).
2. Download the installer for your computer from the banner at the top of your account.
3. On Windows, run the installer. On Mac, open the disk image and drag ChainAI into Applications.
4. Open ChainAI and finish setup. You can connect your AI account later.
5. Open **Context → Connect your account**. Approve the matching code in your browser.

The download banner disappears once your desktop is connected to that company.

[View installers and release notes](https://github.com/ChainAI-Org/chainai-desktop-releases/releases/tag/v0.1.0-beta.1)

Windows installers are signed and timestamped with Workado's Microsoft Azure signing profile. Mac installers are signed with Workado's Apple Developer ID, notarized by Apple, and include a notarization ticket. Each release includes SHA-256 checksums.

This repository contains distribution files only. Application source is maintained separately.
